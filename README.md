# Doubly-Linked-List-CPP

A custom implementation of a doubly linked list using C++ templates.

## Features
- Add elements to front and back
- Remove elements
- Reverse linked list
- Sort linked list
- Dynamic memory management
- Template support for generic data types

## Concepts Used
- Data Structures
- Templates
- Pointers
- Dynamic Memory Allocation
- Object-Oriented Programming
- Exception Handling

## Files
- `LinkedList.h`
- `main.cpp`

## Language
- C++
